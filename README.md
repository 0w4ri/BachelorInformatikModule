# Bachelor Informatik – Module

Persönliche Sammlung meiner Lernunterlagen aus dem Bachelorstudium Informatik (Küster-Chroniken):
Zusammenfassungen, Themenskripte und Cheat Sheets, geordnet nach Modul.

## Struktur

Pro Modul ein Ordner, darin die Unterlagen als PDF (vereinzelt `.txt`-Quellen):

```
Module/
├── <Modul>/
│   ├── <Kürzel>_<Thema>.pdf      # Themenzusammenfassung
│   └── <Kürzel>_CheatSheet.pdf   # Kompaktübersicht (falls vorhanden)
└── …
```

Die Dateinamen beginnen mit einem Modulkürzel (z. B. `Ana_`, `GdB_`, `Lina_`, `WKT_`).
